# nyrv-landing

The static landing page served at [nyrv.dev](https://nyrv.dev).

## What this is

A single-file HTML landing page for NYRV, the independent proof infrastructure project. No build step, no framework, no JavaScript dependencies. The page is hosted on Railway with auto-deploy from this repository.

## What this is not

Product code. The NYRV product itself lives at [github.com/Saabe-CEO/nyrv](https://github.com/Saabe-CEO/nyrv). This repo contains only the marketing surface.

## Files

- `index.html` — the entire landing page, including inline CSS
- `nyrv-html-logo.png` — the NYRV wordmark, served at `/nyrv-html-logo.png`

## Editing

To update content, edit `index.html` directly and push to `main`. Railway auto-deploys.

For larger structural changes, consider whether the change should land here or wait for a more deliberate redesign.
