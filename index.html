Core Directives

Constitutional Principles

NYRV operates under binding architectural constraints. These aren't policies — they're code, verified by tests.

DIRECTIVE 01

Observe Only

NYRV observes and records. It never decides, never acts, never judges. Recognition without authority.

DIRECTIVE 02

Append Only

Events can only be added, never modified or deleted. The ledger is permanent. The record is immutable.

DIRECTIVE 03

No Content Storage

We see metadata, never sensitive data. We know that something happened. We never see what it contained.

DIRECTIVE 04

Independence Always

No sponsorships. No endorsements. No financial relationships with entities we observe. The proof must be independent.

DIRECTIVE 05

Capability Ceiling

NYRV has hard limits. It cannot make autonomous decisions. It cannot execute actions. It cannot expand its own authority.

DIRECTIVE 06

Verifiable by Third Parties

Every claim NYRV makes can be independently verified using public infrastructure. Trust no one — verify.

Architectural Commitments

By Design

The architecture is what's tested. Implementation follows the architecture, not the other way around.

Hash-Chained Integrity

Every event cryptographically links to its predecessor. Tampering at any point breaks the chain. Mathematically provable integrity.

Durable Ledger

PostgreSQL-backed persistence. Append-only schema, enforced in code and at the database level. No update path. No delete path.

Synchronous Evidence

Evidence artifacts returned in the same call as the observation. Your system knows the record was captured before it proceeds.

Evidence Artifacts

Structured proof returned with every observation. Includes timestamp, hash, chain position, and verification path.

Anchored to Sigstore

Designed to anchor chain heads to the public Sigstore Rekor transparency log. Independent verification without contacting NYRV.

Per-Tenant Isolation

Designed for cryptographic boundaries between organizations. Your evidence chain is yours alone. No commingling by design.

Integration

How It Works

One call. Synchronous proof. The architecture is simple because the principle is simple.

1

Observe

Your system sends an event to NYRV when an action occurs.

2

Record

NYRV hashes, chains, and persists the event to the durable ledger.

3

Return

An evidence artifact is returned synchronously with proof of recording.

4

Anchor

Chain heads are anchored to the public Sigstore Rekor transparency log. Anyone can verify.
